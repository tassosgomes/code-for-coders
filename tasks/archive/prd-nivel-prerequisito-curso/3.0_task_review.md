Mudar só o nível → `hasUnpublishedChanges: true` + `draftRevision` cresce; voltar ao valor vigente → `false`; versão vigente intacta (IT compara snapshot da versão 1 antes/depois).

Coberto para `"expert"`, `42`, `true` e array, com assert de que nada muda.
- Idempotência/autorização: repetição da chave devolve resposta idêntica sem nova revisão; chave reusada com corpo diferente → 422 `IDEMPOTENCY_KEY_REUSED`; JWT só com `autoria.ler` → 403; outro tenant → 404; nada muda nos três casos (IT).
